设计理念
Design Concept

本项目的定位是国际协同创新区的配套服务功能板块，规划的功能涵盖人才宿舍(R3)、文体中心以及能源管控中心。该项目具有单一业主、整体开发并且自持自用这样独特的性质。
一旦项目竣工，它会摇身一变成为集园区生活服务与文化体育于一体的大型展示体验区，从而为园区工作人员打造出各种适配性极佳的场景与空间。本项目设计重点在于打造邻里社区与立体街区，营造人文氛围以促进交往交流，构建适合科创青年的社区场景来提升园区运营服务品质，创建混合型、多样型宜居社区。内部空间和园林景观设计要满足住户需求，整体风貌需符合园区城市设计和项目定位，塑造特色建筑形象。场地用地面积30171平方米，建筑容积率:≤2.4;建筑高度:≤100米;计入容积率总建筑面积不超过114500平方米，其中公寓面积为84000平方米、地上产业配套用房12500平方米(含商业2000平方米，文体10500平方米)、地下产业配套用房6500平方米(含文体4500平方米，商业2000平方米)、公共配套设施5500 平方米(含社区健康服务中心1500平方米、社区管理用房300平方米、社区警务室200平方米、110kv变电站3500平方米)、地下建筑供冷用房6000平方米。
