设计理念
Design Concept

保留原有的街巷尺度、空间关系和重要节点。新的建筑以“镶嵌”的方式介入，形成新与旧的对话。多条从英东大道、环市大道延伸至内部公祠、天后古庙的视觉通廊和步行动线。通廊作为景观带和文化展示轴，引导人流自然深入。不大面积使用仿古建筑风格，采用现代材料（如玻璃、金属、清水混凝土）与传统的青砖、瓦片、蚝壳墙等元素结合，创造一种“新岭南”建筑风格，尊重传统，面向未来。


Retain original alley scales, spatial relationships, and key nodes (e.g., heritage banyan trees). New buildings integrate via ​​“tectonic insertion”​​, sparking dialogue between old and new.Establish visual/pedestrian corridors extending from Yingdong Avenue and Huanshi Roads to ancestral halls and Tin Hau Temple. These ​​“culture-ribbons”​​ guide visitors inward while showcasing local heritage.

Reject imitation nostalgia. Combine modern materials (glass, metal, fair-faced concrete) with traditional elements (blue bricks, tiles, oyster-shell walls) to create ​​“New Lingnan”​​ architecture – respecting tradition while embracing the future.
